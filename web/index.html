How unpacking works
Archives written with an open table of contents are read natively — no external tool, no GTA V install needed. Most mod dlc.rpf files are built this way.

Archives using AES or NG encryption hide their file list behind keys stored in GTA5.exe. Those need gtautil, which reads the keys from your own game install.

Select a source folder and the counters above tell you which is which before you start. gtautil only appears if a pack actually needs it.

Generated handling uses class templates, not the original author's tuning. Every one is flagged in the log.

How merging works
Every pack keeps its own folder under stream/ and data/, and its meta files are copied byte for byte. FiveM accepts repeated data_file entries and scans stream/ recursively, so nothing has to be merged at the XML level.

That is what keeps a pack whose single vehicles.meta holds a dozen cars intact — and it means a car that misbehaves points straight at the download it came from.

Escrow-protected resources are never merged. Anything carrying a .fxap only runs under its own resource name, so it is left exactly where it is.

Duplicate spawn codes never stop the run. The same car shipped twice is kept once. A genuinely different build of the same spawn code is renamed name_1 ... name_10, with its model files and metas renamed to match. Engine audio still binds to the original name.
